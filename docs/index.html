Features

What it does

A small, fast 3D editor for interiors, built around one idea: the house is plain data, and every change goes through a checked operation.

🧱

Rooms, doors, windows

Rectangular rooms with real wall thickness, openings measured the way a tape measure does, and checks for overlaps and anything that does not fit.

🛋️

Furniture that looks right

Built-in sofas, beds, tables, wardrobes and more, or any piece you describe from boxes, cylinders and curves. Sizes are in metres.

🎨

Finishes and lights

Paint colours, wood, tiles, fabric, or your own wallpaper photo. Point and spot lights, pendants and downlights.

🚶

Walk through it

Orbit, top plan, cutaway walls, or walk inside a room at eye height with day and night lighting.

📸

Photorealistic render

A path-traced render of your scene with soft light and shadows, saved as a PNG for sharing.

↩️

Undo, save, share

Full undo and redo, save and load house files, and a plain JSON format you can read, diff and version.

AI

Works with AI assistants

Adding a light, a sofa or a fan is an operation, not a code change. An MCP server exposes those operations, so an assistant can design the house while you watch it update live.

🤖

Claude Code plugin

Install the plugin and ask: "Design a 2 BHK, modern, then furnish the living room." It reads the rules, edits your house file and fixes its own mistakes from the validation errors.

🔌

Any MCP client

Ready-made config for Claude Desktop, Cursor, Codex CLI and Gemini CLI, plus instruction files for each.

💬

Chat apps without tools

A copy-paste prompt for ChatGPT, Gemini or any chat app. Paste the JSON reply into the app and press Apply.

Six tools: house_guide house_new house_get house_apply_ops house_validate house_undo. A batch either applies fully or changes nothing.

Quick start

Get started

You need Node.js 20 or newer.

Run the app

git clone https://github.com/harshitalpha/house-tool.git
cd house-tool
npm install
npm run dev

Open the address it prints (usually http://localhost:5173). Pick an example from the Examples menu, or press New.

Edit by hand or by pasting

Click anything to select it and use the Inspect tab, or drag and use the arrow keys. The Prompt tab builds a complete prompt for any AI chat; paste its JSON reply into the Paste tab and press Apply.

Let an AI assistant drive

Pick your assistant. The MCP server is already built in the repo at plugins/house-design/server/house-mcp.mjs, so there is nothing to compile. Replace /path/to/house-tool with where you cloned it.

/plugin marketplace add harshitalpha/house-tool
/plugin install house-design@house-tool

Installs the MCP server and the house-design skill. Without the plugin: claude mcp add house -- node /path/to/house-tool/plugins/house-design/server/house-mcp.mjs

Add this to claude_desktop_config.json (Settings, Developer, Edit Config), then restart the app.

{
  "mcpServers": {
    "house": {
      "command": "node",
      "args": ["/path/to/house-tool/plugins/house-design/server/house-mcp.mjs"],
      "env": { "HOUSE_FILE": "/path/to/my-house.json" }
    }
  }
}

Save as .cursor/mcp.json in your project. Copy integrations/cursor/house-design.mdc to .cursor/rules/ so the agent knows the workflow.

{
  "mcpServers": {
    "house": {
      "command": "node",
      "args": ["/path/to/house-tool/plugins/house-design/server/house-mcp.mjs"],
      "env": { "HOUSE_FILE": "${workspaceFolder}/house.json" }
    }
  }
}

Append to ~/.codex/config.toml. Copy integrations/codex/AGENTS.md into your project as AGENTS.md.

[mcp_servers.house]
command = "node"
args = ["/path/to/house-tool/plugins/house-design/server/house-mcp.mjs"]
env = { HOUSE_FILE = "/path/to/my-house.json" }

Save as .gemini/settings.json (or merge into your existing one). Copy integrations/gemini-cli/GEMINI.md into your project as GEMINI.md.

{
  "mcpServers": {
    "house": {
      "command": "node",
      "args": ["/path/to/house-tool/plugins/house-design/server/house-mcp.mjs"],
      "env": { "HOUSE_FILE": "/path/to/my-house.json" }
    }
  }
}

No tool support needed. In the app, open the Prompt tab: it builds a complete prompt with the rules, every operation and your current house. Paste it into ChatGPT, Gemini, Claude.ai or any chat, then copy the JSON reply into the Paste tab and press Apply. For a reusable system prompt use integrations/prompt-only/house-design-prompt.md. If the app shows an error, paste it back and ask for a fixed batch.

Any other MCP-capable client works the same way: run node /path/to/house-tool/plugins/house-design/server/house-mcp.mjs as a stdio server. The server reads and writes the file in HOUSE_FILE (default ./house.json). To watch the changes live, start the app on the same file:

HOUSE_FILE=/path/to/my-house.json npm run dev -w @house/web

Then ask, for example: "Create a 2 BHK, modern style, and furnish the living room." More detail in docs/ai-tools.md.

Render it

Click Render in the toolbar (orbit or walk mode), choose Draft, Good or Final quality, wait for the noise to clear, then Save image.
